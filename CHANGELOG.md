# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-21

### Added

- Dark luxury theme with CSS custom properties
- Fully responsive layout (6 breakpoints: 480px, 570px, 768px, 1024px, 1200px, 1400px)
- Product carousel with scroll snap
- Mobile navigation with accordion menus
- Newsletter subscription modal
- Notification toast component
- Countdown timer for deals section
- Intersection Observer fade-in animations
- Smooth hover effects on product cards, buttons, and images
- Glassmorphism header with backdrop blur
- Semantic HTML5 markup
- Ionicons 5 icon library integration

### Fixed

- Overlay event listener leak in mobile menu
- Accordion interference between menu sections
- Newsletter form submit handler missing `preventDefault()`
- Toast animation set to play once instead of infinite
- Button-inside-anchor accessibility issue
- Incorrect alt text on jewelry icon
- Invalid HTML time element
- Missing Open Graph image meta tag
- Inconsistent product title markup
- Duplicate blog titles
- Incorrect blog categories
- Swapped price/del values on products
